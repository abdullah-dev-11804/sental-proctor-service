# Kazakh Server Deployment

Target server:

```text
Domain: proctoring.sental.kz
IP: 109.248.247.21
OS: Ubuntu 22.04
CPU/RAM/Disk: 4 vCPU, 16 GB RAM, 200 GB
```

This host is enough for staging, identity verification, and light testing. For
many simultaneous recorded exams, add monitoring and revisit CPU/disk capacity.

## Server Install

SSH into the server:

```bash
ssh root@109.248.247.21
```

Install Docker and Git:

```bash
apt update
apt install -y git ca-certificates curl gnupg ufw docker.io docker-compose-plugin
systemctl enable --now docker
docker compose version || apt install -y docker-compose-v2
docker compose version || apt install -y docker-compose
```

Open staging ports:

```bash
ufw allow OpenSSH
ufw allow 8091/tcp
ufw allow 9000/tcp
ufw allow 9001/tcp
ufw allow 7880/tcp
ufw allow 7881/tcp
ufw allow 50000:50100/udp
ufw --force enable
```

Clone the service:

```bash
cd /opt
git clone YOUR_GITHUB_REPO_URL sental-proctor-service
cd /opt/sental-proctor-service
```

Create the environment file:

```bash
cp .env.kazakhstan.example .env
```

Generate secrets:

```bash
openssl rand -base64 32
openssl rand -base64 32
openssl rand -base64 32
```

Put those values into:

```text
API_SHARED_SECRET
S3_SECRET_KEY
MOODLE_WEBHOOK_SECRET
```

Edit the file:

```bash
nano .env
```

Place the approved production models under:

```text
/opt/sental-proctor-service/models/scrfd_2.5g_kps.onnx
/opt/sental-proctor-service/models/adaface_ir50_ms1mv2.onnx
/opt/sental-proctor-service/models/minifasnet_v2.onnx
/opt/sental-proctor-service/models/SixDRepNet.onnx
```

Start Server B:

```bash
docker compose up -d --build
docker compose ps
```

LiveKit must allow the browser to join the room name generated by the API.
For the current Server B flow, `/opt/sental-proctor-service/infra/livekit.yaml`
must contain:

```yaml
room:
  auto_create: true
```

Check health:

```bash
curl http://109.248.247.21:8091/api/health
curl https://proctoring.sental.kz/api/health
```

Expected:

```json
{"ok":true,"status":"healthy","features":{"identity_engine":"scrfd_adaface","identity_models_ready":true}}
```

## Moodle Settings

In `local_proctorcore` settings:

```text
Enabled: Yes
Server B URL: https://proctoring.sental.kz
Server API key: same as API_SHARED_SECRET
Webhook secret: same as MOODLE_WEBHOOK_SECRET
Verify SSL: Yes
LiveKit browser client URL: empty
Identity threshold: 0.42 initial AdaFace auto-pass threshold
Identity mismatch mode: review during calibration
```

## Redeploy

After pushing changes:

```bash
cd /opt/sental-proctor-service
git pull
docker compose up -d --build
docker compose logs -f api
```
